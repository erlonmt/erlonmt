## Projetos em destaque

### Mural de Enquetes

Aplicação Full Stack para criação, gerenciamento e votação em enquetes, com atualização dos resultados em tempo real.

O projeto foi desenvolvido com foco na integração entre diferentes serviços, autenticação de usuários, persistência de dados e comunicação em tempo real.

**Principais funcionalidades:**

* API REST desenvolvida com Laravel
* Autenticação utilizando Laravel Sanctum
* Criação e gerenciamento de enquetes
* Registro de votos
* Validação para impedir votos duplicados
* Atualização de resultados em tempo real
* Comunicação utilizando WebSocket
* Persistência de dados com PostgreSQL
* Interface desenvolvida em React
* Ambiente containerizado utilizando Docker Compose
* Testes dos principais fluxos da API

**Tecnologias utilizadas:**

`Laravel 11` `PHP` `PostgreSQL` `React` `Vite` `Node.js` `WebSocket` `Docker`

[Ver repositório](https://github.com/erlonmt/mural-enquetes)

---

### Mobile Tickets

Sistema de gerenciamento de senhas desenvolvido para organizar filas de atendimento, com suporte a prioridade automática e painel de chamadas.

O projeto trabalha conceitos de gerenciamento de filas, regras de prioridade e integração entre aplicação cliente, servidor e banco de dados.

**Tecnologias utilizadas:**

`Ionic` `Angular` `Node.js` `MySQL` `TypeScript`

[Ver repositório](https://github.com/erlonmt/MobileTicketsIonic)

### Complexo Hospitalar UPE — Teleagendamento

Sistema web para gerenciamento de consultas médicas, desenvolvido com foco no controle de agendamentos e validação de disponibilidade.

**Principais funcionalidades:**
